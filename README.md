## 🧠 Problem-Solving Approach

For every problem, I try to follow this process:

```text
1. Understand the problem
        ↓
2. Identify the input and output
        ↓
3. Find the simplest possible approach
        ↓
4. Analyze edge cases
        ↓
5. Implement the solution
        ↓
6. Test with examples
        ↓
7. Analyze Time & Space Complexity
        ↓
8. Look for possible optimization
```

The goal is not only to solve the problem, but also to understand **why the solution works**.

## ⚡ Complexity Matters

I am also focusing on understanding the efficiency of each solution.

For example:

### Best Time to Buy and Sell Stock

Instead of checking every possible pair of buying and selling days, the solution maintains:

* Minimum price encountered so far
* Maximum profit possible so far

This allows the problem to be solved in:

```text
Time Complexity:  O(n)
Space Complexity: O(1)
```

Understanding these optimizations is an important part of this challenge.
