## 🧠 About the Challenge

**50 Days of LeetCode** is my personal **Data Structures & Algorithms practice challenge**, where I solve and document LeetCode problems consistently using **Python**.

The goal is not simply to increase the number of problems solved.

The real objective is to build the ability to:

* 🧩 Recognize common DSA patterns
* 🧠 Break complex problems into smaller steps
* ⚡ Write efficient and optimized solutions
* 📊 Analyze time and space complexity
* 🐍 Improve Python problem-solving skills

* 💼 Prepare for technical interviews and coding assessment.

> **Consistency compounds. Every problem solved is another pattern understood.**

# ⚙️ Complexity Analysis

Each solution focuses on understanding:

### Time Complexity

How the runtime grows as the input size increases.

Examples:

```text
O(1)       Constant
O(log n)   Logarithmic
O(n)       Linear
O(n log n) Linearithmic
O(n²)      Quadratic
```

### Space Complexity

How much additional memory the algorithm requires.

The objective is not always to achieve the lowest possible complexity, but to understand the **trade-offs between time, memory, readability, and implementation complexity**.

```text

                 │
                 ▼
       Identify Input & Output
                 │
                 ▼
        Find a Simple Approach
                 │
                 ▼
          Consider Edge Cases
                 │
                 ▼
          Write the Solution
                 │
                 ▼
             Test Cases
                 │
                 ▼
      Time & Space Complexity
                 │
                 ▼
          Optimize if Possible
```

The objective is to understand **the pattern behind the problems, rather than memorizing individual solutions.
