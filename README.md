# 🧠 Problem-Solving Approach

For each problem, I try to follow a structured process:

```text
              Problem
                 │
                 ▼
        Understand the Question
                 │
                 ▼
       Identify Input & Output
                 │
                 ▼
        Find a Simple Approach
                 │
                 ▼
          Consider Edge Cases
                 │
                 ▼
          Write the Solution
                 │
                 ▼
             Test Cases
                 │
                 ▼
      Time & Space Complexity
                 │
                 ▼
          Optimize if Possible
```

The objective is to understand **the pattern behind the problems, rather than memorizing individual solutions.

# 📌 Challenge Rules

### Rule 1️⃣ — Solve Every Day

Solve at least **one LeetCode problem every day**.

### Rule 2️⃣ — Understand the Solution

Don't simply copy a solution. Understand the approach and reasoning.

### Rule 3️⃣ — Analyze Complexity

For every problem, try to identify:

```text
Time Complexity
Space Complexity
```

### Rule 4️⃣ — Learn From Mistakes

If the first solution is inefficient, understand why and look for a better approach.

### Rule 5️⃣ — Stay Consistent

> **Missing one difficult problem is better than missing the entire challenge.**
